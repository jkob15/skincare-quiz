# AI Skincare Recommendation Quiz

A web app that walks users through a short skincare quiz and 
(planned) generates personalized product recommendations using AI 
based on their answers.

## Status: In Progress

**Done:**
- Multi-step quiz interface built with vanilla HTML, CSS, and JavaScript
- Dynamic question navigation with per-question answer validation
- Client-side state management for tracking selected answers
- Custom UI with CSS gradients, hover/active states, and Google Fonts

**Planned:**
- Store user responses in a structured format (JS object/array)
- Integrate an AI/LLM API to generate personalized skincare 
  recommendations based on quiz answers
- Display recommended products to the user

## Tech Stack
- HTML / CSS / JavaScript (no framework)
- Google Fonts (DotGothic16, Valley Sans)

## Why I'm building this
I'm interested in gaining more experience in full-stack web development and API integration, and I have an existing interest in skincare, so I wanted to integrate the two into a project.
